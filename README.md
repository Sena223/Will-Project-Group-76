
# Sydney Opera House Visitor RAG Chatbot

A Retrieval-Augmented Generation (RAG) chatbot that answers visitor questions about the Sydney Opera House, built by reproducing the method used in Walert (RMIT's own research chatbot project: https://github.com/rmit-ir/walert), applied to a new domain.

## What's in here

- `data/` — our real data: 187 passages from the official Opera House website, 50 topics with 80 question phrasings, and 6 off-topic test questions
- `src/` — all the code
- `target/` — the built search index and evaluation results (generated by running the steps below, not committed to git since it's rebuilt from the code and data)

## One-time setup (do this once per laptop)

1. **Install Java 21** (needed for the search engine):

winget install Microsoft.OpenJDK.21

   Close and reopen your terminal after this finishes, then find your install path with `where.exe java`, and set:

setx JAVA_HOME "C:\Program Files\Microsoft\jdk-21.x.x.x-hotspot"

   (use your actual installed path). If you keep hitting "Unable to find JAVA_HOME" even after this, add it to your PowerShell profile so it's set automatically every new terminal:

if (!(Test-Path -Path $PROFILE)) { New-Item -ItemType File -Path $PROFILE -Force }
Add-Content $PROFILE '$env:JAVA_HOME = "C:\Program Files\Microsoft\jdk-21.x.x.x-hotspot"'


2. **Install Python 3.11** (older Python versions can fail to build some dependencies):

winget install Python.Python.3.11


3. **Create a virtual environment** (run from this project's root folder):

py -3.11 -m venv .venv
.venv\Scripts\Activate.ps1

   Your terminal prompt should now show `(.venv)`.

4. **Install the Python packages:**

pip install -r requirements.txt

   This takes a few minutes — it pulls in a lot of dependencies (this is normal, not frozen).

5. **Install Ollama** (free, local AI model used for generating answers):

winget install Ollama.Ollama
ollama pull llama3.2:1b
pip install ollama


## Running everything (after setup, or any time you want to rebuild)

Run all of these from inside the `src/` folder, with `.venv` activated.

1. **Generate the search-ready files from our data:**

python data.py


2. **Build the search index** (only needs to be done once, or after changing the data):

mkdir ..\data\collection
move ..\data\collection.jsonl ..\data\collection
python -m pyserini.index.lucene --collection JsonCollection --input ../data/collection --language en --index ../target/indexes/bm25 --generator DefaultLuceneDocumentGenerator --threads 1 --storePositions --storeDocvectors --storeRaw

   Look for `Indexing Complete! 187 documents indexed` at the end.

3. **Run retrieval** (searches all 80 questions against the index):

python search.py


4. **Run evaluation** (scores accuracy — NDCG and Recall):

python eval.py

   Expected real results: NDCG@1/3/5 ≈ 0.686/0.638/0.643, Recall@5/10 ≈ 0.645/0.794

5. **Check the unanswered-question threshold:**

python unanswered_eval.py

   Expected: 13/80 in-scope questions wrongly declined, 1/6 off-topic questions wrongly answered, at threshold 4.5.

## Talking to the chatbot

python chatbot.py


Type any question about the Opera House (parking, tours, accessibility, dining, security) and it'll search the real data and generate an answer using a local AI model, along with its source passage ID and confidence score. Type an off-topic question (like about the weather or sports) to see it correctly decline. Type `quit` to exit.

Example:

You: How do I get to the Sydney Opera House?
Bot: You can get to the Sydney Opera House by public transportation, walking, or cycling.
(source: P084, retrieval score: 5.53)


## Known real finding (worth citing in the report)

The question "How do I change a flat tyre on my car?" — completely unrelated — gets wrongly answered because it shares the word "car" with our car-park passages. This is a real limitation of keyword-based (BM25) search: it matches words, not meaning.

## Method

Same method as Walert, applied to a different domain (as per the assignment brief's own recommendation): real pyserini/Lucene BM25 indexing and retrieval, real ranx evaluation library for NDCG/Recall scoring, same data schema (topics.csv / collection.csv / groundtruth.csv / qrels.txt). Generation uses Ollama (a free, local LLM) instead of Falcon, since Falcon needs GPU-class hardware we don't have — a disclosed, practical substitution.

## Troubleshooting

- **"Unable to find JAVA_HOME"** — Java is installed but the environment variable isn't set for this terminal session. Run `$env:JAVA_HOME = "<your java 21 path>"` to fix it immediately, and see the PowerShell profile fix in the setup section above for a permanent fix.
- **"UnsupportedClassVersionError"** — you have the wrong Java version installed (need Java 21, not 17).
- **`pip install` seems frozen** — it's usually not frozen, just slow; pyserini pulls in large dependencies (torch, transformers). Give it several minutes before assuming something's wrong.
